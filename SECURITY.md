# Security Policy

## Supported Versions

Currently, only the latest release of LifeXOS is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them to the repository maintainers privately. We will acknowledge receipt of your vulnerability report, and we will send you regular updates about our progress. If your report is accepted, we will coordinate the public disclosure of the vulnerability with you.
