## Root Directory

```text
E:\lifeos-day-main
├── electron/          # Main process code for the Electron desktop app
├── supabase/          # Supabase configuration, migrations, and edge functions
├── tests/             # Playwright End-to-End (E2E) tests
├── package.json       # Dependencies and NPM scripts
├── tailwind.config.ts # Tailwind CSS configuration and theme settings
├── vite.config.ts     # Vite bundler configuration

```

## `src/` Directory Breakdown

```text
src/
├── assets/            # Static assets (images, global CSS if any)
├── components/        # Reusable React components
│   ├── ui/            # shadcn/ui primitive components (Button, Dialog, Input, etc.)
│   ├── AppLayout.tsx  # Main application layout wrapper
│   ├── AppSidebar.tsx # Global navigation sidebar
│   ├── OrbitAI.tsx    # Orbit Orbit AI UI component
│   └── ...            # Other shared components (TaskItem, QuickAdd, etc.)
├── contexts/          # React Context providers (e.g., ThemeContext, AuthContext)
├── hooks/             # Custom React hooks encapsulating logic
│   ├── useLifeXOS.ts            # Core business logic and data fetching
│   ├── useOrbitMemory.ts        # Manages AI memory and context
│   ├── useOrbitNotifications.ts # Handles AI push notifications
│   └── useOffline.ts            # Network connectivity status
├── integrations/      # Third-party API integrations (if any beyond Supabase)
├── layout/            # Layout specific wrappers
├── lib/               # Utility functions and shared helpers (e.g., utils.ts for Tailwind merge)
├── pages/             # Route-level page components
│   ├── Auth.tsx       # Login / Registration
│   ├── Landing.tsx    # Public landing page
│   ├── MyDay.tsx      # Daily planner view
│   ├── Planned.tsx    # Upcoming scheduled tasks
│   ├── Habits.tsx     # Habit tracker
│   ├── Notes.tsx      # Markdown note editor
│   ├── Goals.tsx      # Goal setting and tracking
│   ├── Settings.tsx   # User and workspace settings
│   └── ...            # Other pages (Study, Pomodoro, Insights)
├── App.tsx            # Main application component, sets up React Router
├── index.css          # Global CSS imports and Tailwind directives
└── main.tsx           # React DOM entry point
```

## Architectural Guidelines for the Structure

1. **Pages vs. Components:** 
   - `pages/` contain components that represent a full route (e.g., `/habits`). They handle data fetching and pass props down.
   - `components/` are presentation-focused or encapsulate specific interactive UI elements (like `SortableTaskList`).
2. **shadcn/ui:** All primitive UI components generated by shadcn live strictly in `components/ui/`.
3. **Hooks:** Any complex state logic or data fetching that can be reused across components should be extracted into the `hooks/` directory.
